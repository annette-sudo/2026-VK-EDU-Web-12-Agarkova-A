# 2026-VK-EDU-Web-12-Agarkova-A

## ДЗ№1

Статическая вёрстка форума. 

## Как открыть
Папку репозитория открыть целиком.

PyCharm: File → Open, затем в проекте открыть `public/index.html`. В меню View → Open in Browser.

VS Code: File → Open Folder. Нужно расширение Live Server. Дальше клик правой кнопкой мыши по `public/index.html` → Open with Live Server.

## Страницы
- `public/index.html` — список новых вопросов
- `public/question.html` — страница одного вопроса и ответы
- `public/ask.html` — форма нового вопроса
- `public/login.html` — вход
- `public/signup.html` — регистрация
- `public/profile.html` — настройки профиля
- `public/base.html` — общий каркас: header, контент, sidebar, footer

Стили, скрипты и картинки лежат локально в `public/static/`.
